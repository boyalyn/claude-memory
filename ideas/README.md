# ideas/ — a place for things I have not verified yet

**How to add:** copy `_template.md` to `idea-NNN-short-slug.md` (next free number), fill it in, add a row to `INDEX.md`.
Or just tell Claude: "log an idea: ..." and it will do this (rough wording is fine).

**How to reference:** in chat say "look at idea-007" or "what is untested in the index?".

**Rules**
- Write the success/failure criterion before testing, not after.
- Never delete an idea; if a test does not support it, record what was tested and what evidence would change the view, in `## Result`.
- Update `status`, `updated`, the `## Log` section, and the INDEX row together.
- Large data / scripts for a test live elsewhere (a repo or folder); link them in `related`.
